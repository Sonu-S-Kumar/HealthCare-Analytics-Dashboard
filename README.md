# HealthCare-Analytics-Dashboard
🏥 HealthCare Analytics Dashboard
An interactive and insightful Power BI dashboard built to analyze patient admissions and operational efficiency in a healthcare facility.

📌 Project Overview
The HealthCare Analytics Dashboard offers a detailed visualization of hospital operations including patient flow, bed occupancy, departmental performance, and length of stay. Designed for hospital administrators and healthcare analysts, this dashboard supports strategic decisions to optimize resources and improve patient outcomes.

🎯 Purpose
To explore and visualize healthcare data using Power BI, focusing on operational KPIs such as patient admission patterns, bed utilization, and treatment outcomes. It empowers healthcare leaders to:

🛠 Tech Stack
Power BI – Interactive visual analytics and dashboard creation.
Power Query – ETL layer for data transformation and cleaning.
DAX (Data Analysis Expressions) – Measures, KPIs, and logic-based calculations.
Excel – Source dataset preparation.

✨ Features & Highlights
📊 Key KPIs:
Total Admissions
Discharges
Bed Occupancy Rate
Average Length of Stay (ALOS)
Bill Amount vs Health Insurance Amount

🧮 Department & Diagnosis Insights:
Number of patients by department or diagnosis
Bed occupancy by category
ALOS by diagnosis or ward

🏆 Performance Analysis:
Departments with longest and shortest stays
Most common diagnoses
Trends in patient flow
